# Website 1: Adare Restaurant landing page

A single-page restaurant landing page in plain HTML and CSS. It is the first project from the course *Web Design Essentials: Zero to Hero*.

**[▶ View it live](https://shzunknown11.github.io/Website-1/)**

## What's in it

- Full-screen background image with a centred logo and headline
- Hand-written CSS in `style.css`, no frameworks
- Two files of code: `index.html` and `style.css`

## Run locally

Clone the repo and open `index.html` in a browser.
